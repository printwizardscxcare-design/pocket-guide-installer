Windows, macOS, and Linux release with the same selective core and game checklist, Add and Overwrite modes, and firmware-only option.

Downloads include Windows x64 EXE, macOS Intel and Apple Silicon DMG/ZIP, and Linux x64 DEB, RPM, Arch package, and portable TAR.GZ. Each build is checked on its native OS. Linux packages are installed and checked on Debian, Fedora, and Arch.

macOS builds are ad-hoc signed and are not Apple-notarized. A physical Pocket transfer on macOS and Linux still needs user testing. Credits are included with every build.
