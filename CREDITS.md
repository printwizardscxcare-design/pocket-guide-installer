# Credits and upstream sources

This project depends on the work of FPGA developers, port maintainers, catalog maintainers, and tool authors. The core names below identify the builds selected by this installer. Each linked project maintains its own contributor history, upstream acknowledgments, and license terms.

## Guide, platform, and download services

- **Damien McFerran and Time Extension** wrote the guide used to select the supported systems and arcade titles. [Guide](https://www.timeextension.com/guides/all-analogue-pocket-openfpga-cores-and-where-to-download-them)
- **Analogue** develops the Pocket hardware, Analogue OS, and openFPGA framework, and publishes the firmware downloaded by the installer. [openFPGA documentation](https://www.analogue.co/developer/docs) · [Pocket firmware](https://www.analogue.co/support/pocket)
- **Internet Archive and the openFPGA-Files collection contributors** host the indexed game and system assets. Asset filenames and checksums in the installer manifest came from this collection. Each game's creators, publishers, and rights holders retain their respective rights. [Collection](https://archive.org/details/openFPGA-Files)

## Installer and artwork

The installer application and its checklist interface were created for this repository. The smiling handheld artwork was generated with OpenAI's image-generation tool and converted into a Windows icon using Pillow. The executable is packaged with PyInstaller and includes Python, Tcl, and Tk runtime components.
